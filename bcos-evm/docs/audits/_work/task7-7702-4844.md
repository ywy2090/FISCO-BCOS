## Step 2 — EIP-7702 preCheck（inventory #7, preCheck 半部）

### FB 实现（`OpStackPreCheck.cpp:62–96`）

| 规则 | FB | op-geth `preCheck` |
|------|----|--------------------|
| Sender EOA 或 delegation code | `get_code(sender)` + `parseDelegationTarget` | `ParseDelegation` + `ErrSenderNoEOA`（`:391–396`） |
| `gasFeeCap >= gasTipCap`, `>= baseFee` | ✅ | ✅ `:411–420` |

**判定：✅** — 已实现规则与 op-geth 语义对齐（status 映射为 `Malformed` 可接受）。

## Step 3 — EIP-7702 intrinsic gas（inventory #7, intrinsic 半部）

### FB（`OpStackExecuteViaHost.cpp:24-30` + `EthTxGasSettlement.h:73-76`）

```cpp
// computeIntrinsicGasDebit:
return base + calcAuthTupleIntrinsicGas(authTupleCount);
// calcAuthTupleIntrinsicGas = authTupleCount × PER_EMPTY_ACCOUNT_COST (25_000)
```

- `base` = `computeTxIntrinsicGas(...).preExecutionDebit()`（21000 + calldata + access list + CREATE term）
- 在 `executeEntryChecks` 中：`gasLimit < intrinsic` → `OutOfGasLimit`
- `applyAuthorizations` 侧：authority 已存在时 refund `PER_AUTH_BASE_COST`（12_500）→ 净 12_500；新账户无 refund → 净 25_000 ✅

### op-geth（`IntrinsicGas` + `innerExecute`）

```go
if authList != nil {
    gas += uint64(len(authList)) * params.CallNewAccountGas  // 25_000 per tuple
}
// applyAuthorization: if Exist(authority) → AddRefund(CallNewAccountGas - TxAuthTupleGas)
```

| 场景 | op-geth 净 intrinsic / auth | FB (54e17a62c) | 一致 |
|------|----------------------------|----------------|------|
| authority **已存在** | 25000 − 12500 refund = **12500** | 25000 pre − 12500 refund | ✅ |
| authority **不存在**（新账户） | **25000**（无 refund） | 25000 | ✅ OP-07 |
| 无 auth list | 0 | 0 | ✅ |

**判定：✅ CLOSED (OP-07)** — `calcAuthTupleIntrinsicGas` 使用 `PER_EMPTY_ACCOUNT_COST`（25_000），与 op-geth `CallNewAccountGas` 预扣模型一致。

### 测试（54e17a62c）

| 测试 | 覆盖 | 判定 |
|------|------|------|
| `OpStack7702ExecuteViaHostPropagationTest::opStackExecuteViaHost_rejects_7702_intrinsic_below_25000_per_tuple` | gasLimit < 21000+25000 → OOG | ✅ |
| `OpStack7702ExecuteViaHostPropagationTest::opStackExecuteViaHost_charges_7702_intrinsic_25000_per_tuple` | 2 tuples × 25000 门槛 | ✅ |
| `OpStack7702ExecuteViaHostPropagationTest::opStackExecuteViaHost_propagates_authorizations_to_executeMessage` | apply + stateDiff | ✅（仍 `skipTransactionChecks`） |

**剩余缺口：** 无 dedicated「新 authority 净 25000 vs 已存在净 12500」余额/gasLeft 对照；propagation 用例仍 skip preCheck/balance。
